# Cherry Studio

Cherry Studio 适合桌面聊天和多模型切换。接入 DouDi 时选择 OpenAI 兼容类型。

## 配置步骤

1. 打开 Cherry Studio 设置。
2. 进入服务商或模型服务配置。
3. 新增自定义 OpenAI 兼容服务商。
4. 填写 API Key 和 Base URL。
5. 添加模型名并保存。

## 推荐值

```text
Provider Type: OpenAI Compatible
Base URL: https://doudi.ai/v1
API Key: 你的 DouDi API Key
Model: 控制台可用模型名
```

## 常见问题

如果模型下拉框没有自动出现，手动添加模型名即可。若对话失败，先确认 Key 余额、模型权限和分组是否支持该模型。
