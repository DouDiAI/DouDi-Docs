# Claude Code 配置

[Claude Code](https://claude.com/product/claude-code)  是 Anthropic 官方推出的 AI 编码 CLI 工具。通过 DouDi.ai，你可以获得默认 100 RPM、TPM 不限的调用配额，以及更低延迟和多模型切换能力。

![Claude Code in Terminal](/imported/haoai/integrations-claude-code-01.webp)

## 为什么使用 DouDi.ai？

*   **高速率配额** — 默认 100 RPM，TPM 不限，满足高频编码需求
*   **高可用** — 多节点冗余，自动故障切换
*   **低延迟** — 全球加速节点，自动最优路由
*   **完整协议支持** — 100% 兼容 Anthropic 原生协议
