# 常见问题

排查 DouDi 请求时，最重要的是留下请求时间、模型名、Key 名称、分组、状态码和 request ID。

## 401 未授权

优先检查 API Key：

- 是否复制完整。
- 前后是否有空格或换行。
- 是否使用了错误账户的 Key。
- Key 是否被禁用、删除或过期。

## 403 无权限

常见原因：

- 当前 Key 的分组不支持该模型。
- 账户没有对应权限。
- 客户端走了不支持的接口类型。
- 特定模型需要单独开通。

## 429 限速或并发限制

429 不一定是模型坏了。先确认：

- 客户端是否同时发起太多请求。
- Key 是否有频率限制。
- 分组或渠道是否有并发限制。
- 上游是否返回限速。

下游生产服务应实现退避重试，并限制同一 Key 的瞬时并发。

## 413 请求体过大

减少图片大小、附件数量、上下文长度或历史消息数量。多模态请求尤其要注意单次请求体大小。

## 模型名不可用

先打开 [模型广场/价格页面](https://doudi.ai/pricing)，复制当前可用模型名。不要只根据旧教程或其他站点复制模型名。

## 回复很慢

先看 [使用日志](https://doudi.ai/usage-logs/common) 里的耗时和实际命中渠道。首字慢可能来自长上下文、上游排队、模型本身慢、渠道切换或客户端网络。

## 扣费不符合预期

核对模型、分组、输入长度、输出长度、缓存、图片和固定消耗。下游批量任务上线前，应先用真实样本做成本验证。
