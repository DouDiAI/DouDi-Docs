# 订阅与套餐

DouDi 可能提供余额充值、套餐、兑换码或其他运营方案。最终可购买项以控制台实际展示为准。

## 怎么选

| 需求 | 建议 |
| --- | --- |
| 偶尔测试 | 小额余额或试用额度 |
| 稳定个人使用 | 选择适合常用模型的套餐 |
| 下游服务 | 联系运营确认分组、并发和预算 |
| 高峰调用 | 先压测，再确定套餐和线路 |

## 下游接入前要确认

- 是否需要专用分组。
- 目标模型是否长期可用。
- 峰值并发大概是多少。
- 每日预算和单 Key 限额是多少。
- 失败切换是否会影响成本。

## 变更套餐

变更前先确认剩余额度、有效期和新套餐生效时间。生产服务不要在高峰期切换关键 Key 或分组。
