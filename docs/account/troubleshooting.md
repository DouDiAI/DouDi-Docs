# 账户问题排查

账户问题通常和登录方式、余额、Key 状态或分组权限有关。先从控制台当前页面和请求日志确认事实。

## 无法登录

检查：

- 登录方式是否选对。
- 邮箱或第三方账号是否一致。
- 浏览器是否拦截了回调或 Passkey 弹窗。
- 是否同时在 `doudi.ai` 和 `www.doudi.ai` 之间切换。

## 看不到某个功能

可能原因：

- 当前账户权限不足。
- 后台关闭了对应模块。
- 移动端菜单折叠，需要展开侧栏。
- 功能只对特定角色或分组开放。

## Key 不能用

按顺序检查：

1. Key 是否完整复制。
2. Key 是否被禁用或过期。
3. 账户余额是否足够。
4. Key 分组是否支持该模型。
5. 请求日志是否有更具体的错误。
