# 账户概览

DouDi 控制台用于管理账户、余额、Key、请求日志、价格页、订阅和发票等信息。具体入口会随站点配置调整，以页面实际显示为准。

## 第一次登录后先做什么

1. 检查余额或套餐额度。
2. 创建一个测试用 API Key。
3. 打开价格页，确认目标模型和分组。
4. 完成一次小请求。
5. 在请求日志里核对状态码和消耗。

## 常用页面

| 页面 | 用途 |
| --- | --- |
| 钱包或余额 | 查看余额、充值和消费 |
| API Key | 创建、禁用和轮换 Key |
| 模型广场或价格页 | 查看可用模型和计费 |
| 请求日志 | 排查失败、延迟和扣费 |
| 个人设置 | 管理登录方式和账户资料 |
| 发票或订单 | 查看订单记录和开票信息 |
